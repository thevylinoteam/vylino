# Changelog

## 0.2.0 - 2026-09-17

- Added Google Gemini Interactions API adapter using stateless `store=false` requests.
- Added Gemini model/key settings with `gemini-3.6-flash` default.
- Added human agent reply composer in the WordPress inbox.
- Human replies automatically take over the conversation and pause AI.

## 0.1.0 - 2026-09-17

- Created initial WordPress plugin bootstrap.
- Added database schema for CRM, conversations, messages, knowledge, deals, follow-ups and audit events.
- Added WhatsApp Cloud API text sender.
- Added signed Meta webhook verification/receiver.
- Added secure message ingestion and duplicate-message protection.
- Added human handoff detection and manual takeover/release.
- Added WordPress admin dashboard, settings and inbox foundation.
