# Vylino Business OS — Phase 1 Roadmap

## Objective
Deliver a usable single-window operating system for Vylino covering lead management, sales, clients, projects, SEO, Search Console, GA4 and WordPress.

## Milestone 1 — Foundation
- Keep `main` stable.
- Use `develop` for integration work.
- Create feature branches for each implementation area.
- Establish architecture and module boundaries.

## Milestone 2 — Branding and Navigation
- Rename visible product experience to Vylino Business OS where appropriate.
- Add Vylino logo and branding assets.
- Add navigation groups for Dashboard, CRM, Sales, Projects, SEO, Ads, Social, Website, Analytics, Automation and Settings.

## Milestone 3 — CRM and Sales
- Reuse Twenty People, Companies, Opportunities, Tasks and Activities.
- Add Vylino lead/source fields.
- Configure pipeline stages: New, Contacted, Qualified, Meeting, Proposal, Negotiation, Won, Lost.
- Capture UTM, GCLID, FBCLID, landing page, service interest, estimated value and next follow-up.

## Milestone 4 — Clients and Projects
- Create Client, Project, Website and Service objects where not covered by core objects.
- Link won opportunities to delivery projects.
- Track platform, domain, delivery status, assigned team, maintenance and payment state.

## Milestone 5 — Dashboard
- New leads
- Qualified leads
- Open opportunities
- Pipeline value
- Won revenue
- Active projects
- Due tasks
- Marketing source breakdown

## Milestone 6 — SEO Workspace
- SEO Project
- Keyword
- SEO Page
- SEO Issue
- SEO Opportunity
- Content Brief
- Workflow: Opportunity → Planned → Writing → Review → Published → Optimizing

## Milestone 7 — Search Console
- OAuth connection
- Properties
- Queries
- Pages
- Clicks
- Impressions
- CTR
- Average position
- Opportunity detection

## Milestone 8 — GA4
- Properties
- Users and sessions
- Landing pages
- Events
- Conversions
- Source / medium
- Traffic-to-lead reporting where identifiers allow

## Milestone 9 — WordPress
- Connect vylino.com first.
- List pages and posts.
- Content status and last update.
- Controlled publishing/editing later.
- Keep destructive actions permission restricted.

## Definition of Phase 1 Complete
A Vylino user can sign in to one application, manage leads and opportunities, see sales/project status, review SEO/GSC/GA4 data, and inspect WordPress content without switching between multiple platforms for routine monitoring.
